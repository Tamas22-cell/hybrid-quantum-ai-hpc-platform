# Security

This is a research prototype with public registration and per-user workload isolation. Passwords use salted scrypt hashes. Session tokens are random, stored hashed in PostgreSQL, and issued in `HttpOnly`, `SameSite=Lax`, production `Secure` cookies with seven-day expiry. Redis applies rate limits to registration, login and each user's submissions. A job's owner is checked before status is returned, and saved results are filtered by `user_id`; legacy unowned rows are hidden. Keep Redis, PostgreSQL and metrics private. Never expose raw worker or database ports. Registration currently has no email verification or password reset. Report vulnerabilities privately via the repository's security reporting feature if enabled. No production security certification is claimed.
